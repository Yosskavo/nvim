<h1 align="centre"> Welcom to Nvim config </h1>

# requirement 

- nvim v0.11 or higher
- nerd font (Jet Brain recommanded)
- lazygit (for the git)
- fd (optional)
- rg (optional)
- clangd (for handling c/c++)

# installing 


```sh
# go to the config folder
cd ~/.config/

# make a back-up for your current nvim config
mv nvim nvim-cp

# clone our config
git clone https://github.com/Yosskavo/nvim.git  # or git@github.com:yosskavo/nvim.git if you prefer ssh one

```
