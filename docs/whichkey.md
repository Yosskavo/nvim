# Which-Key

Configured in:

- plugin spec: `lua/plugins/which-key.lua`
- setup: `lua/config/which-key.lua`

## Behavior

- loads on `VeryLazy`
- custom rounded popup window
- explicit width/height/position tuning
- grouped prefixes are registered for discoverability

## Registered groups

- `<leader>s` screen
- `<leader>b` buffers
- `<leader>f` find/files
- `<leader>t` terminal
- `<leader>l` lazy
- `<leader>m` makefile
- `<leader>h` help
- `<leader>x` lsp/trouble
- `<leader>w` lsp workflow
- `<localleader>f` formatting
- `<localleader>s` additional local actions

Use Which-Key to inspect mappings in real time as you type prefixes.
