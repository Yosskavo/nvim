# Extensions (Plugins)

Plugins are declared in `lua/plugins/*.lua` and configured mainly in `lua/config/*.lua`.

## Core UX/UI

- dashboard, lualine, which-key, notify, noice, dressing
- bufferline, web-devicons, colorizer, trouble, screenkey, transparent, ufo

## Search / Navigation

- telescope + fzf-native + live-grep-args
- fzf-lua, grug-far, project.nvim, yazi, flash, cheatsheet

## LSP / Completion

- lspconfig, mason, mason-lspconfig
- nvim-cmp + luasnip + cmp sources + lspkind + friendly-snippets + lsp_signature + lazydev

## Git / Workflow

- gitsigns, lazygit, todo-comments, glance

## Editing helpers

- autopairs, surround, dial, mini.indentscope, hover, cppman, 42-header, whisk, neogen, render-markdown

## Utility and integrations

- plenary, nui, lush, switcheroo, cord, typr/volt, neo-tree, promise-async, make.nvim

## Treesitter

- `nvim-treesitter/nvim-treesitter`
- `nvim-treesitter/nvim-treesitter-context`
